How to create new Repo

first create a empty repo on 
**Github**

then create a Project named f.e. 
**"H03"**

then go to the console and type 
**"git init"**

then type git remote add origin git@github.com:DerTaktischeHase/<REPO_NAME>.git
f.e.
**"git remote add origin git@github.com:DerTaktischeHase/uebungsblatt-3.git"**

then type 
**"git add ."**

then commit your changes with
**" git commit -m "first commit" "**

then push it to GitHub origin
**"git push -u origin main"**


```
git init
git remote add origin git@github.com:DerTaktischeHase/uebungsblatt-3.git
git add .
git commit -m "first commit"
git push -u origin main
```
